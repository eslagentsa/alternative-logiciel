## FAQ

### Pourquoi quitter Brave ?

Brave est excellent mais reste **basé sur Chromium** (Google). Certains critiquent aussi le modèle BAT et l'intégration crypto croissante. Firefox offre une vraie indépendance technologique.

### Firefox est-il aussi rapide que Brave ?

Non, **Brave est plus rapide** sur le JavaScript et les applications web complexes. Mais Firefox reste très fluide pour la navigation quotidienne et offre une meilleure gestion mémoire.

### Quelle différence entre Tor Browser et Brave Tor ?

**Tor Browser** route tout le trafic via le réseau Tor (3 sauts, anonymat fort, lent). **Brave Tor** utilise Tor uniquement pour l'onglet privé Tor (1 hop, moins sûr, plus rapide).

### Safari est-il meilleur pour la vie privée ?

Sur iOS/Mac, **Safari** offre d'excellentes protections avec Intelligent Tracking Prevention et iCloud Private Relay. C'est probablement le meilleur choix dans l'écosystème Apple.

### Comment transférer mes favoris de Brave ?

Tous les navigateurs importent facilement depuis Brave (Chromium). Firefox, LibreWolf, et autres proposent un import à la première utilisation.
