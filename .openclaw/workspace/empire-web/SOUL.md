# Empire Web - Site Monétisable

## Architecture du Projet

### Structure
```
empire-web/
├── sites/                    # Sites déployés
│   └── alternative-logiciel/ # Premier site
├── content/                  # Articles générés (Markdown)
├── templates/               # Templates Astro réutilisables
├── scripts/                 # Scripts d'automatisation
└── docs/                    # Documentation projet

```

## Stack Technique

- **Framework**: Astro 5.x
- **Styling**: Tailwind CSS
- **CMS**: Keystatic (git-based)
- **Hébergement**: Planethoster (The World)
- **Email**: esl.agentsa@gmail.com
