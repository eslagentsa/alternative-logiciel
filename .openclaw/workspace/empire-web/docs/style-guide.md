# Guide de Style - Empire Web

## Ton de Voix

### Caractéristiques
- **Expert mais accessible**: Pas de jargon inutile
- **Objectif**: Comparaisons honnêtes, pas de favoritisme
- **Pratique**: Focus sur l'usage réel, pas les specs techniques
- **Actuel**: Mises à jour régulières, "en 2026"

### Exemples

❌ **À éviter:**
"Notion est une plateforme de productivité all-in-one qui permet de..."

✅ **À préférer:**
"Vous cherchez à remplacer Notion ? Voici 10 alternatives testées et comparées."

## Structure d'Article Type

```
# Title (60-70 caractères, keyword en début)
## Introduction (150 mots)
- Hook: Problème utilisateur
- Promise: Ce qu'il va apprendre
- Preview: Structure article

## Pourquoi chercher une alternative ? (200 mots)
- Limitations outil actuel
- Besoins non couverts
- Coûts

## Critères de sélection (150 mots)
- Méthodologie de test
- Facteurs clés (prix, features, UX)

## Top 10 Alternatives (1200 mots)
### 1. [Nom] - [Tagline]
- Présentation
- Points forts (3 bullets)
- Prix
- Pour qui ?

### 2-10. [Répéter structure]

## Tableau Comparatif
| Outil | Prix | Fonctionnalités | Support | Note |

## Notre Recommandation (200 mots)
- Meilleur choix global
- Meilleur rapport qualité/prix
- Meilleur gratuit

## FAQ (200 mots)
- 3-5 questions courantes

## Conclusion (150 mots)
- Résumé
- Call-to-action
```

## Règles SEO

### Titles
- 50-60 caractères
- Keyword principal en début
- Format: "[Nombre] [Keyword] [Année/Qualificatif]"

Exemples:
- ✅ "Top 10 Alternatives à Notion (2026)"
- ✅ "Meilleures alternatives gratuites à Trello"

### Meta Descriptions
- 150-160 caractères
- Keyword + call-to-action

Exemple:
"Découvrez les 10 meilleures alternatives à Notion en 2026. Comparatif détaillé, prix, avis. Trouvez l'outil parfait pour votre productivité."

### Headers
- Un seul H1 par page
- H2 pour les sections principales
- H3 pour les sous-sections
- Keyword dans premier H2

### Liens
- **Internes**: 3-5 liens vers autres articles
- **Externes**: vers sources officielles (nofollow si concurrent)
- **Affiliation**: balises ?ref= et disclaimers

## Formatage

### Listes
- Bullets pour features
- Nombres pour classements
- Maximum 7 items par liste

### Tableaux
- Comparatifs clairs
- 4-6 colonnes maximum
- Header avec fond gris

### Images
- Format WebP
- Alt text descriptif avec keyword
- Caption quand pertinent
- Lazy loading

### Blocs spéciaux
```markdown
:::tip[Astuce]
Contenu mise en valeur
:::

:::warning[Attention]
Points importants
:::
```

## Checklist Pré-Publication

- [ ] Title < 60 caractères
- [ ] Meta description < 160 caractères
- [ ] Keyword dans H1
- [ ] Keyword dans premier H2
- [ ] Keyword dans première phrase
- [ ] Keyword dans conclusion
- [ ] 3-5 liens internes
- [ ] 2-3 liens externes (nofollow)
- [ ] Images avec alt text
- [ ] Tableau comparatif
- [ ] FAQ Schema
- [ ] Lien affiliation avec disclaimer
- [ ] Passage Copyscape (plagiat)
- [ ] Relecture orthographe
