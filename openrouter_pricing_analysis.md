# OpenRouter Content Generation Model Analysis
*Compiled: March 2026*

## Overview

This analysis covers current OpenRouter pricing for content generation models, categorized by cost/quality ratio for specific use cases.

---

## Pricing Tiers Explained
- **Prices are per-million-tokens (input/output)**
- For a 2000-word article (~2500 tokens input + 2500 tokens output):
  - **Budget**: ~$0.01-0.10
  - **Mid-tier**: ~$0.25-1.50
  - **Premium**: ~$5.00-30.00

## How to Calculate Your Costs

For a typical 2000-word workflow:
- **Input**: ~2,500 tokens (prompt + brief)
- **Output**: ~3,500 tokens (article text)
- **Equation**: (InputPrice/1M × 2500) + (OutputPrice/1M × 3500)

**Examples per 2000-word article**:
| Model | Calculation | Cost/Article |
|-------|-------------|--------------|
| Qwen2.5 72B | ($0.12×0.0025)+($0.39×0.0035) | **~$1.67** |
| Gemini 2.0 Flash | ($0.10×0.0025)+($0.40×0.0035) | **~$1.65** |
| Claude 3.7 Sonnet | ($3.00×0.0025)+($15.00×0.0035) | **~$60.00** |
| GPT-4o | ($2.50×0.0025)+($10.00×0.0035) | **~$41.25** |
